# 换身体证据包（问题 / 方法 / 两次实测 / 可复现命令 / 边界）

> 一句话：**机器人会返厂、会换代、会多机部署。那时候买方要问的不是"它聪明吗"，是"它还是不是上次那个它"。**
> 这份包回答后者，并且**当场可以复现**。

---

## 一、问题

一台机器人（或一个 agent）的"身体"换掉之后：
- 它还是不是同一个它？
- 它记不记得自己经历过什么？
- 谁来证明——它自己说"我记得"，能算证据吗？

**我们的回答：不算。要有第三方能验的账。**

## 二、方法（三件东西）

```
1  一本账：每条记录带 prev|seq|ts|kind|ref|sha，hash 链式相连，只增不改
2  外部锚：每晚把账本 tip 推到外部（GitHub / 云端 / 另一台机器），
          让"内部账"有一个身体外的参照
3  身份签名：Ed25519 对 instance_id|version|sha16|ts 签名，
          证明"是同一个实例"，而不是"同一个 URL"
```

## 三、两次实测（2026-11-27，都可复现）

**实测 1：同一本账，换一个身体，还能验**
```
身体 A = X1 宿主；身体 B = docker 容器（挂载同一本账，HOME/TZ 对齐）
A 侧 verify：✓ 5,327 条，头 4a154fb1055a… 尾 d899457ce9d1…
B 侧 verify：✓ **5,327 条，头尾 hash 与 A 完全一致**
```
→ 结论：账本可迁移，迁移后"是不是同一本账"是**可验的**（比 hash，不比说法）。

**实测 2：A 死、B 接管、A 复活**
```
阶段：A 写 5 条 → A 停 → B 接管写 5 条 → A 恢复写 3 条
交接段 25 条记录：**链连续（每条 prev 都对得上 seq-1 的 hash）**
整本 verify：✓ 5,371 条，尾 8df8661932b5…
A 最后写 → B 第一次写：**实际间隔 3 秒**（A 自己的节拍是 2 秒）
```
→ 结论：**"身体死了、另一个接上、账本不断"是真的跑出来的，不是推演。**

## 四、可复现命令（5 分钟）

```bash
# 前提：docker + python3
cd ~/nian
bash tools/body_swap_drill.sh          # 起 B 容器 → A 写 → B 接管 → A 恢复 → 验证 → 清理
# 期望输出最后一行：
#   ✓ 结论：身体换了，账本接上了（同一本账、链连续）
```

另外两个小工具：
```bash
python3 tools/body_migrate.py --check    # 迁移清单：必须带 / 可以缺 / 必须对齐
python3 tools/body_migrate.py --verify   # 在当前身体自检：文件齐不齐、账能不能验
```

## 五、边界（先说清做不到什么）

```
✔ 已验：账本可迁移、跨身体可验、交接期账本不断链
✘ 未验：实时性——我们落盘是秒级，具身控制是毫秒级，没测过这个延迟对控制回路的影响
✘ 未验：进程状态转移——这次只迁了"账"，没迁"正在想什么"（记忆上下文/推理中间态）
✘ 未验：外部锚在交接期是否连续（本轮没触发锚，需另测）
✘ 没有第三方客户——所有数字都是自测，没有外部复现
```

## 六、这一层为什么值钱（商业判断，非技术判断）

```
展台上卖的是身体：能走、能抓、能表演。
身体是商品，也是**耗材**：会坏、会换代、会批量部署。
每一台换下来的身体，都在问同一个问题——"里面那个它还认得出自己吗"。
我们不造身体；我们做**身体里那一层不会被换掉的东西**。
```
