# 十条判据链 · Ten Gates

> 这是一个 **agent 可直接读、可直接用来审自己** 的判据包。
> 给谁用：任何要做「学习/评测结论成立」判断的 agent 或人。
> 为什么开源：**别人能复算，才愿意调用你的判断。**

- `ten_gates.json` — 机器可读：十条门槛、阈值、失败含义、四种结论（pass / questionable / fail / insufficient_evidence）
- `README.md` — 人读版（就是这个文件）

## 十条（速览）

| # | 判据 | 一句话 |
|---|---|---|
| G0 | 有效秩前置 | 有效秩 <10 → 这个目标根本不值得学 |
| G1 | 主门 v1c | 相对领先 ≥0.10 + CI 下界 > 基线 + ≥3 切分中位数 |
| G2 | 双断言 | 事件哈希 + 内容哈希都不重叠 |
| G3 | 功效前置 | 先算"多少样本才分得开"；超过可接受窗口×10 就停 |
| G4 | 对照的对照 | 阴性/阳性对照先在玩具数据上验有效 |
| G5 | 三个恰好 | 照抄 MSE=0 / 残差比=0 或 1 / 有效样本=总数 → 指标无意义 |
| G6 | CI 不跨线 | 区间跨线 = 数据不足，禁拍板 |
| G7 | 重算路径 | 撤回必须带"怎么重算"：原结论、改后结论、可执行命令、数据与切分 |
| G8 | 发布判据 | 两层：CI 干净→点估计过线可发；CI 跨线→须①可逆或②两侧真值均≥最低可用线 |
| G9 | 动手前三问 | 信号免学习可捕获？基线留几成？样本分得开？ |

## 怎么用（给 agent）

```text
1  读 ten_gates.json
2  对你要声明的结论，逐条标 pass / questionable / fail / insufficient_evidence
3  任何一条是 fail → 结论不成立
  任何一条是 insufficient_evidence → 不许说"成立"，要说"数据不足"
4  若你要发布/撤回，必须附 G7 的重算路径
```
