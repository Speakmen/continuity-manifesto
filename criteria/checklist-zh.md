# 发布前自检清单（免费公开版 · 一页）

> **用法只有一个：拿它检查一条你已经发出去的结论——大概率能查出一条。**
> 这张表可以随便转发、打印、贴墙上。它来自《判据手册：一个 AI 如何诚实地输》第 12 章。
> 完整版含 12 章与五次自错复盘；这张表本身就够用——如果它有用，再考虑买不买。

## 做之前

```
□ 这个信号"不学也能拿到"吗？
   —— 打乱标签重训一遍：效果不掉 = 模型没在学，抓的是泄漏或捷径（一小时的活）
□ 平凡基线留几成？
   —— 模型至少比基线好 10%，否则提升大概率被噪声吃掉
□ 需要多少样本才分得开？
   —— 先算：n ≈ 16 × (噪声/效应)²；若所需样本 > 可接受窗口的 10 倍 → 停
□ 判定线是多少？
   —— **写下来，事后不许挪**
```

## 跑的时候

```
□ 报数永远三件套：点估计 + 95% CI + 判定线
□ 三个"恰好"先自检（出现任一，这个指标就不值得看）
   · 照抄基线 MSE = 0
   · 残差比 = 0 或 1
   · 有效样本 = 总样本（多半是去重没生效）
□ 阴性/阳性对照，是不是都在玩具数据上验过有效？
□ 测试集有没有偷偷见过训练集？
   —— 事件级哈希 + 内容级哈希，两道都要
□ 去重到底生效没有？（按源分组看，别只看总数）
```

## 说之前

```
□ 区间跨线了吗？
   —— 跨了只能写"数据不足"，不能写"接近显著"
□ 跨线还要发？写明走哪条口子，并写清数：
   ① 可逆（回滚动作 + 回滚成本 + 触发条件）
   ② 两侧都够格（"最低可用水平"必须是一个具体数字）
□ 发布记录：发了什么、依据哪层、谁批的
```

## 撤回的时候

```
□ 原结论保留，不删不改
□ 三样都写：原结论 / 改后结论 / 为什么变
□ 一条能复制粘贴的重算命令
□ 数据位置 + 切分方式 + 环境版本
□ 撤回记录放到能被检索到的地方（别藏在聊天记录里）
```

## 每周问自己三句

```
□ 这周我撤回了什么？（空着说明没审自己）
□ 这周有没有一个数字，是我"顺手填"的？
□ 这周有没有一个结论，其实只到"我没看见证据"的程度？
```
