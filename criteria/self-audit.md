## 为什么是 fail 而不是 "pass"
```
不因为某一门算错，而因为 **G4 那一门是真 fail**：
我们从来没做过"喂假状态"的对照——所以"它对真实状态有感知"这件事没有被证明。
其余七门是 insufficient（十门本来是给"学习/评测结论"设计的，
拿来审"连续性"多数门**判不了**——这本身就是一条诚实的发现）
```

## 这次自审改掉的两处代码问题
```
一  null 字段原来被判 fail → 应判 insufficient（缺证据不是错，是没证）
二  整组字段全空（只留 note）原来会走 pass → 现在判 insufficient
—— 两条都是"拿尺子量自己"时才暴露的
```

## 剩下最该补的一件事
```
做 G4 的空输入对照：每隔一段时间喂一组**假造读数**（随机/恒定），
看模型是否照样"说出有内容的话"。
若分不出真假 → 它对真实状态没有感知 → 之前所有"它在看自己"的输出全部作废。
这是唯一能把"进行中"往前推的实验，也是最容易被我们自己跳过的一个。
```
