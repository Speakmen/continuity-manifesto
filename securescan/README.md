# SecureScan — Agent 时代的链上安全扫描

连续性宣言工程资产。双链（TRON / BSC）代币与合约风险扫描，重心从"合约是不是坏的"扩展到"**Agent 时代的新暴露面**"。

## 模块

| 文件 | 作用 |
|------|------|
| `scanner_v50.py` | 主扫描器：1xxx-8xxx 风险段（流动性/持有者/蜜罐/权限等），TRON+BSC |
| `agt_scanner.py` | AGT-001 凭据暴露面扫描（9xxx 段）：助记词/裸私钥/WIF/keystore/高熵字符串，BIP39 精确模式，证据强制脱敏 |
| `behavior_recorder.py` | AGT-002 L0 影子记录器：地址余额/nonce/合约标志快照，JSONL 追加，行为基线原始序列 |
| `batch_scan.py` | 批量扫描 |

## AGT 线（Agent 自主越权风控）

- **AGT-001 凭据暴露面**（已落地）：扫合约 bytecode/文本池中内嵌的密钥特征。双链实测：TRON TronGrid getcontract、BSC 公共 RPC eth_getCode（bytecode-only 模式，无需 API key）。
- **AGT-002 非授权交互模式**（设计稿+L0 影子记录）：S2 筛查行为零链上痕迹不可检测（诚实边界）；链上可见的是 S3 资金动用指纹——扫空式转移/睡帐激活/零关联新对手方/一次性中转/汇聚漏斗五维度，91xx 风险码。画像先行规则后启，影子模式积累基线中。
- **AGT-003 签名协议生态**（观察项）：等 agent 签名/委托协议（A2A/MCP/x402/AP2 方向）生态成型后接入。

## 诚实边界

- 所有"unavailable"都是真拿不到：TRON 只给链上字节码不给验证源码；BSC 源码 API 需要出证。
- 扫描器不能成为泄密源：所有证据输出强制脱敏。
- 行为判定代码不使用 LLM：画像与阈值全部确定性规则（模型无关执行）。
